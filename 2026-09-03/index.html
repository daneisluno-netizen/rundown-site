  • ! Failure stat — cites "the MIT study" for ~95% of businesses failing to show AI ROI. Confirmed real (MIT NANDA, Jul 2025), but the video omits the study's sharpest finding: internally built tools fail ~95%, externally sourced tools succeed 67% of the time.

T minus365 copilot frontier early access

watch it (7 minutes, direct admin how-to)

T-Minus365 (Nick) · work lane · 7m5s video → ~3m read | uploaded 9 Aug 2026

TOPICS COVERED

  • Feature — Microsoft Frontier is Microsoft's real, named early-access program for pre-GA Microsoft 365 Copilot features. Confirmed against Microsoft Learn, not just the video's word.
  • Control — managed at tenant level in admin.cloud.microsoft → Copilot → Settings → Frontier; scopeable to all users, specific users, or groups (e.g. an MSP's own pilot/champion group).
  • ! Admin role gap — video says Global Admin or "AI admin" can enable it. Learn's actual list is AI Admin, Security Admin, or Office Apps Admin — the video didn't mention Security Admin or Office Apps Admin as valid least-privilege options.
  • Prerequisite — requires an active Copilot licence (or the sub-300-seat Business add-on); not available on base M365 plans.
  • Propagation delay — after enabling, the admin panel updates in ~5 minutes but users may not actually see new features for up to 24 hours — worth knowing before troubleshooting a "why isn't it there" ticket.
  • Gotcha — under Copilot → Agents → Settings, "Allow apps and agents built by Microsoft" must also be ticked, or Frontier-released agents (his example: Copilot "co-work") won't appear even with Frontier on.
  • Agent-level control — individual agents can be further restricted to specific users/groups even after Frontier is enabled tenant-wide, for granular pilot scoping.
  • Change-risk note — cites Copilot's "co-work" feature as an example of a Frontier feature whose UI and billing model both changed materially between preview and GA — a real caution for anyone documenting a pre-GA feature for a client.

WORTH YOUR TIME IF: you manage M365 tenants and want a pilot group testing Copilot features before end users ask about them.

SKIP IF: you don't hold a Copilot licence in any managed tenant — the whole video is gated on that prerequisite.

DO THIS: if you or a client tenant has Copilot licensed, enable Frontier scoped to a small pilot group (not "all users") via admin.cloud.microsoft → Copilot → Settings → Frontier, and note the ~24h propagation delay before assuming it's broken.

BOTTOM LINE

Straightforward, low-token admin walkthrough of a real Microsoft program. No hype, no unverifiable claims beyond one loosely-named feature ("Copilot co-work") that reads like informal shorthand rather than a Learn-documented product name.
